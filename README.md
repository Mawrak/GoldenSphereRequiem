# Golden Sphere: Requiem
This is a port of the Golden Sphere STALKER mod to SoC engine, with the aim of adding new graphics and story and fixing various errors (including save game corruptions), without bloating the game too much or increasing system requirnments. 

Very WIP, Cordon is playable but can be unstable, REPO is a mess and will be cleaned, so don't hold onto those hashes too much.
